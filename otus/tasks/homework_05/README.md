## Установка
Перед началом работы сохраните директорию со всем содержимым https://downgit.github.io/#/home?url=https://github.com/yunusov/python/tree/master/otus/tasks/homework_05 на диск. Перед началом работы требуется сконфигурировать должным образом файл 'src/.env'. Данный файл отсутствует, требуется создать копию файла 'src/.env.example', переименовать её в 'src/.env', в самом файле требуется задать собственные значения для следующих параметров. В скобках указан пример содержимого:

*MIDDLEWARE_SECRET_KEY*=секретный ключ для SessionMiddleware (любая-строка)

*SERVER_IP*=IP вашего сервера (127.0.0.1)

*SERVER_PORT*=порт вашего сервера (8000).


## Использование
Запустите файл *start.bat*.
По умолчанию работа ведётся с файлом *phone_dict.json* находящийся в директории *src/storage*. При необходимости файл с данными телефонного справочника создаётся.

Чтобы запустить тесты выполните файл *start_test.bat* из той же директории. Напротив каждого теста должно быть слово "PASSED" свидетельствующее о корректном прохождении.

Мной был разработан телефонный справочник хранящий следующую информацию о контакте: имя, телефон, комментарий, кем создан контакт, а также уникальный идентификатор. Первым делом хочется показать страницы, наличие которых является необходимым для задания. Это представление /about, где можно увидеть информацию о разработчике и приложении, а также корневая страница, где находится форма авторизации в приложении. В данной форме пользователь просто вводит желаемое имя и нажимает кнопку <Отправить>. Это нужно чтобы разные пользователи могли работать со своим набором данных, записями отмеченными их логином. Либо с общедоступными записями, не имеющими определённого владельца. В этом можно убедиться залогинившись под разными пользователями. Пользователю admin доступны для работы все записи имеющиеся в хранилище.

Залогинившись в систему пользователю открывается ряд новых возможностей. Становится доступен просмотр записей и поиск по ним. Для поиска в поле ввода в правом верхнем углу надо ввести желаемый текст, вхождение которого будет искаться во всех полях всех записей, и нажать кнопку <Поиск>. Отобразятся найденные соответствующие критерию поиска записи. Под ними показывается информация об их количестве. Для того чтобы вернуться к просмотру всех записей можно нажать кнопку в левом верхнем углу <Домой>.
Следующая доступная пользователю функция — это добавление контакта. Чтобы добавить контакт пользователь должен нажать в левом верхнем углу кнопку <Добавить контакт>. После нажатия откроется форма создания контакта в полях ввода необходимо указать требуемые данные — имя, телефон, комментарий и нажать кнопку <Сохранить>. Чтобы прервать создание и перейти к работе с таблицей данных пользователь может нажать кнопку <Домой>.

Чтобы изменить данные в созданной записи пользователь должен нажать на кнопку <Редактировать контакт> расположенную рядом с кнопкой удаления в правой части каждой строки. После нажатия на кнопку редактирования откроется форма аналогичная той что была при создании записи. На ней пользователь также может внести необходимые коррективы и нажать кнопку <Сохранить>.
Для того чтобы детально посмотреть информацию о желаемой записи пользователь должен кликнуть на неё. Откроется форма с данными пользователя.

Пользователь может удалить созданную запись нажав кнопку <Удалить контакт> находящуюся в правой части каждой строки. При этом система задаст вопрос о корректности удаления записи и если пользователь подтвердит, то удаление произойдёт.
Чтобы завершить работу в приложении от имени выбранного пользователя нужно в правом верхнем углу нажать на логин и выпавшую кнопку <Выход>. В результате пользователь опять окажется на форме авторизации с предложением ввести имя.
